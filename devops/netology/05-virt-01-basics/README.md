## Задача 2. Выбор платформы виртуализации

### 1) Высоконагруженная MySQL (критичная к отказу)
**Выбранный вариант:** `Виртуальная машина с репликацией MySQL (двухузловой мастер-слейв/галерея + резервное копирование) + выделенный диск`

### 2) Разные web-приложения
**Выбранный вариант:** `Контейнеризация (Docker), для масштабирования — кластер контейнеров`

### 3) Windows-окружение для бухгалтерии
**Выбранный вариант:** `Традиционная ВМ (или VDI), чтобы сохранить совместимость с Windows-приложениями/драйверами`

### 4) Высокопроизводительные расчёты на GPU
**Выбранный вариант:** `Выделенный сервер/инстанс с GPU (не контейнеры на shared-инфре без доступа к графике)`

Критерии выбора (кратко): `Нагрузка, требования к отказоустойчивости, изоляция, лицензионные ограничения, масштабируемость и стоимость`

## Задача 3. Системы управления виртуализацией

### Сценарий 1
**Выбор:** `KVM / QEMU как базовый слой для локальной инфраструктуры и совместимых Linux workload`

### Сценарий 2
**Выбор:** `Proxmox или vSphere при необходимости удобного web-управления и ролловера ВМ`

### Сценарий 3
**Выбор:** `Docker + Docker Compose для типовых приложений и CI-проверок`

### Сценарий 4
**Выбор:** `Kubernetes для продовых/масштабируемых сервисов с автоматическим rollout и self-healing`

Краткое обоснование:
`Сначала выбирается правильный уровень абстракции под сценарий: где нужна изоляция и совместимость — ВМ, где скорость/масштаб — контейнеры, где оркестрация и контроль SLO — Kubernetes.`

## Задача 4. Гетерогенная среда

### Проблемы и недостатки
- `Сложнее эксплуатация и диагностика: разные модели мониторинга/логирования`
- `Непрозрачность стоимости и лицензий между платформами`
- `Риск рассинхронизации конфигураций (разные образы, версии, патчи, политики безопасности)`

### Что сделать для минимизации рисков
- `Стандартизировать образы и инфраструктуру через IaC (Terraform/Ansible)`
- `Единая observability: метрики, логи, алерты и CMDB`
- `Регулярные тесты восстановления, политики backup + контроль прав доступа`

### Была бы такая среда у меня?
- `Да/Нет`
- `Почему: да, если есть единые процессы и автоматизация; иначе риск роста расходов и хаоса`
